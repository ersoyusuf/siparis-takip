# Pasta Sipariş Defteri — Banka Dekontu Takip 

Sipariş, dekont ve favori müşteri takibi için tarayıcı tabanlı, tek dosyalık bir uygulama.

- Veriler tarayıcıda (IndexedDB) ve isteğe bağlı olarak Firebase Firestore üzerinde saklanır.
- Aynı "hesap e-postası" girilen cihazlar aynı sipariş listesini paylaşır.

## Yayınlama

Bu depo GitHub Pages ile yayınlanmak üzere hazırlanmıştır. `index.html` dosyası depo kök dizininde durduğu sürece Pages ayarlarından (Settings > Pages > Branch: main, Folder: / (root)) etkinleştirmek yeterlidir.
